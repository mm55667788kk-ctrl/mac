# سهرة MAC — تطبيق آيفون (IPA)

نفس واجهة سهرة MAC ونفس المحركات، لكن كتطبيق مستقل بدون Scriptable:

- رسائل الواجهة أسرع بكثير (بضع أجزاء من الثانية بدل ربع ثانية).
- التطبيق يجلب الفيديو بنفسه من أي سيرفر، فلا يمنعه السيرفر من التشغيل داخل التطبيق.
- «مشغّل النظام» يفتح مشغّل آبل الأصلي (صورة داخل صورة و AirPlay).
- الصوت يستمر والشاشة مقفلة.

## 1) بناء ملف IPA بدون ماك (مجاناً عبر GitHub)

1. سجّل في github.com (مجاني).
2. اضغط **New repository**، اكتب اسماً مثل `sahra-mac`، ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب **كل محتويات هذا المجلد** (بما فيها مجلد `.github`)، ثم **Commit changes**.
   - في ويندوز: افتح المجلد بعد فك الضغط، حدّد كل ما فيه (Ctrl+A)، واسحبه إلى الصفحة.
   - إذا لم يظهر مجلد `.github` في الرفع: من **Add file → Create new file** اكتب الاسم `.github/workflows/build-ipa.yml` والصق محتوى الملف نفسه.
4. افتح تبويب **Actions**، اختر **Build SahraMAC IPA**، ثم **Run workflow**.
5. بعد 3–6 دقائق افتح التشغيل الأخضر، وفي أسفل الصفحة تحت **Artifacts** نزّل **SahraMAC-ipa**. داخله الملف `SahraMAC.ipa`.

إذا ظهر التشغيل باللون الأحمر: افتح خطوة **Build the IPA** وانسخ آخر الأسطر وأرسلها.

## 2) تثبيته على الآيفون

- **Sideloadly** (ويندوز، مجاني): وصّل الآيفون بالكمبيوتر، اسحب `SahraMAC.ipa` إلى Sideloadly، وادخل بحساب Apple ID. بحساب مجاني يعمل التطبيق 7 أيام ثم تعيد التثبيت بنفس الطريقة.
- أو **ESign / Scarlet / GBox** على الآيفون إذا عندك شهادة.
- أو **TrollStore** إذا كان جهازك يدعمه (بدون انتهاء صلاحية).

بعد التثبيت (مع Sideloadly): الإعدادات ← عام ← إدارة الأجهزة ← وثّق حسابك.

## 3) أول تشغيل

التطبيق منفصل عن Scriptable، فأضف اشتراك الماك مرة أخرى.

## للمطوّرين (على ماك)

`bash build-ipa.sh` يبني `SahraMAC.ipa` مباشرة (Xcode 15 أو أحدث، iOS 15 وأحدث).
